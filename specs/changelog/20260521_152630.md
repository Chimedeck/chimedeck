# Changelog — 2026-05-21 15:26:30

## Update
- Fixed board-list refresh behavior after board creation in both workspace boards views so users no longer need a manual browser refresh to see newly created boards.
- Added an order-safety guard for board list fetches: stale/out-of-order fetch responses are ignored instead of overwriting fresher state.

## New
- `BoardListPage` create flow now triggers a post-create refetch to revalidate server truth.
- `WorkspaceDashboard` create flow now triggers the same post-create refetch.
- `BoardListPage` Redux state now tracks `activeFetchRequestId` to accept only the latest fetch result.

## Technical Debt
- Board list currently mixes optimistic local mutation and server revalidation in component handlers; this could be centralized in thunk orchestration to reduce duplicated behavior.
- Similar stale-response protection may be needed in other pages using overlapping fetches and mutations.

## What Should Be Done Next
- Add an integration test for "create board while initial boards fetch is still in-flight" to prevent regressions.
- Consider lifting post-create refetch behavior into `createBoardThunk` so all callers get identical consistency guarantees by default.
