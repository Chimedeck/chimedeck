# Changelog — 2026-06-03 20:14:32

## Update

- **BoardPage** (`src/extensions/Board/containers/BoardPage/BoardPage.tsx`): Added `'documentation'` to the `BoardTab` union type. Added a `githubProjectUrl` state + `useEffect` that fetches `getBoardIntegrations` on mount and sets the URL. The Documentation tab is conditionally appended to the tabs array only when `githubProjectUrl` is a non-empty string, placing it directly after Health Check. Tab content renders `<SpecsWorkspacePage boardId={boardId} />`.

## New

- **SpecsMarkdownEditor** (`src/extensions/DeveloperDocs/components/SpecsMarkdownEditor.tsx`): TipTap-based markdown editor component with a formatting toolbar (H1/H2/H3, bold, italic, inline code, ordered/unordered list, code block, blockquote, horizontal rule). Serializes to raw markdown via `@tiptap/markdown`. Props: `content`, `onChange`, `readOnly`.

- **SpecsFileTree** (`src/extensions/DeveloperDocs/components/SpecsFileTree.tsx`): Recursive file-tree component rendered from a flat `{ path, sizeBytes }[]` manifest. Builds a nested folder/file structure, sorts folders before files, renders expand/collapse buttons for folders, file buttons with dirty-state amber dot indicator. Props: `files`, `selectedPath`, `dirtyPaths: Set<string>`, `onSelect`.

- **SpecsWorkspacePage** (`src/extensions/DeveloperDocs/containers/SpecsWorkspacePage/SpecsWorkspacePage.tsx`): Split-pane workspace container. Fetches `GET /api/v1/boards/:boardId/specs/manifest` on mount, then `GET /api/v1/boards/:boardId/specs/files?path=...` on file selection. Uses `useReducer` state machine with loading / loaded / error states for both manifest and file. Dirty tracking via `Set<string>` — marks a file dirty when editor content diverges from fetched content. Props: `{ boardId: string }`.

- **BoardPage.documentation.test.tsx** (`src/extensions/Board/containers/BoardPage/__tests__/BoardPage.documentation.test.tsx`): 6 tests covering: tab hidden when `github_project_url` is null / empty string; tab visible when URL is present; Documentation tab placement immediately after Health Check; clicking tab renders `SpecsWorkspacePage`; tab hidden when integrations fetch fails.

- **SpecsWorkspacePage.test.tsx** (`src/extensions/DeveloperDocs/components/__tests__/SpecsWorkspacePage.test.tsx`): 7 tests covering: loading state, error state with retry, empty manifest state, file-tree render after manifest load, "Select a file" prompt before selection, file content fetch on selection, retry re-fetches manifest.
