# Iteration 5: Entitlements + Usage API (Sprint 159)

## Update
- Added workspace entitlements resolver that maps stored tier IDs to canonical tier quotas.
- Added workspace usage aggregation to compute current consumption of plan-limited resources.
- Implemented GET `/api/v1/workspaces/:workspaceId/entitlements` endpoint to expose entitlements + usage.
- Properly integrated SUBSCRIPTIONS_ENABLED fallback behavior with DEFAULT_UNLIMITED_TIER config.

## New

### `server/extensions/subscription/common/entitlements.ts`
- **`WorkspaceEntitlements` interface**: Maps feature keys to tier quotas (workspace, board, list, member, guest, storage, rate limits).
- **`resolveEntitlements(tier)`**: Maps stored tier IDs (tier_1/tier_2/unlimited) to canonical tier names (free/pro/enterprise) and returns full entitlements object.
- **`TIER_ID_MAP`**: Mapping between stored tier IDs and canonical tier names, preserving backward compatibility with existing subscription records.

### `server/extensions/subscription/common/usage.ts`
- **`WorkspaceUsage` interface**: Aggregated usage metrics for workspace-bounded resources.
- **`getWorkspaceCount()`**: Count non-archived workspaces (framework for future user-scoped counting).
- **`getBoardCountPerWorkspace(workspaceId)`**: Count boards in a workspace.
- **`getMaxColumnsPerBoard(workspaceId)`**: Find highest column count across boards in workspace.
- **`getMaxInvitedMembersPerBoard(workspaceId)`**: Find highest member count across boards.
- **`getMaxGuestsPerBoard(workspaceId)`**: Find highest guest count across boards.
- **`getStorageBytesUsed(workspaceId)`**: Aggregate storage from non-deleted attachments.
- **`getWorkspaceUsage(workspaceId)`**: Orchestrate all usage queries in parallel.

### `server/extensions/subscription/api/getEntitlements.ts`
- **`handleGetEntitlements(req, pathname)`**: API handler for GET `/api/v1/workspaces/:workspaceId/entitlements`.
- Extracts workspaceId from pathname, fetches subscription tier, resolves entitlements, aggregates usage, returns JSON response.
- Respects SUBSCRIPTIONS_ENABLED flag: if disabled, uses tier_1 (free) unless SUBSCRIPTIONS_DEFAULT_UNLIMITED_TIER is true.

### Updated `server/extensions/subscription/api/index.ts`
- Wired new getEntitlements route to subscription router with pattern matching `/api/v1/workspaces/:workspaceId/entitlements`.

## Technical Debt

- Usage endpoint does not currently filter by user permissions; add authorization middleware in iteration 6.
- Tier ID mapping is hardcoded; could be externalized to database for dynamic tier management.
