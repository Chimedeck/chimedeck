# Update
- Reworked edit-mode hyperlink interactions in the card description Tiptap editor.
- Added link hover configuration trigger, link configuration popover, and inline link edit popover.
- Added icon actions in link config: edit, open in new tab, copy URL, and delete link.

# New
- Edit mode now shows a link configuration button when hovering links in the rich text editor.
- Clicking a link in edit mode now opens the link configuration UI instead of redirecting.
- Link display presets were added in edit mode:
  - full URL display
  - button-like display
  - card-like display with title and domain line
- Enter key support was added in the link edit popover to apply link edits.

# Technical Debt
- Link display presets are currently represented with link text/class transformations in the editor and may not survive markdown round-trip serialization depending on markdown output constraints.
- Link config popover positioning is viewport-relative to the editor scroll container and may need refinement for edge cases in very small viewports.
