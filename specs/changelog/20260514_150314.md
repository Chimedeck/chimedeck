# Update
- Added custom field value change activities using action `card.custom_field.updated` from `PUT` and `DELETE` flows in the card custom field value API.
- Added activity payload shaping for readable values across field types (text, number, date, checkbox, dropdown).
- Added server/client activity visibility allowlist entries for `card.custom_field.updated`.
- Added board activity translation and variable interpolation support for custom field activity data.
- Added card modal activity label rendering for custom field updates.

# New
- New board activity sentence: `{actor} updated {fieldName} with {newValueDisplay} on "{cardTitle}"`.
- New card activity sentence: `updated {fieldName} with {newValueDisplay} on this card`.

# Technical Debt
- Date display for activity values currently uses a fixed `en-US` formatter in server formatting logic and may need localization alignment with the client locale/i18n system.
- The fallback for cleared values uses plain text `empty`; if product copy changes, this should be centralized with i18n constants.
