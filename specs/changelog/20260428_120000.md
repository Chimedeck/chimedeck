## Update
- Extended custom field value upsert flow to emit an automation event when a card custom field value actually changes (no-op saves are ignored).
- Registered a new RULE trigger type for custom field value changes in the automation trigger registry.
- Upgraded Rule Builder trigger configuration UI to support board custom field selection and type-specific value inputs.
- Added a new CARD action type to update custom field values from automation rules.
- Upgraded Action configuration UI to support board custom field selection and type-specific value editors.
- Improved rule edit action row rendering for custom-field actions to display field name and chosen value.
- Updated custom-field action copy from "Update custom fields value" to "Change custom fields".

## New
- Added trigger handler: `card.custom_field_value_updated`.
  - Trigger label: `Update custom fields value`
  - Config supports:
    - `fieldId` (required)
    - `fieldType` (required: TEXT | NUMBER | DATE | CHECKBOX | DROPDOWN)
    - expected value key based on field type (`valueText`, `valueNumber`, `valueDate`, `valueCheckbox`, `valueOptionId`)
- Added action handler: `card.update_custom_field_value`.
  - Action label: `Update custom fields value`
  - Config supports:
    - `fieldId` (required)
    - `fieldType` (required: TEXT | NUMBER | DATE | CHECKBOX | DROPDOWN)
    - target value key based on field type (`valueText`, `valueNumber`, `valueDate`, `valueCheckbox`, `valueOptionId`)
- Added dynamic TriggerConfig rendering for custom field triggers:
  - Loads board custom fields from `/boards/:boardId/custom-fields`
  - Dropdown custom fields render option picker from existing field options
  - Input custom fields render typed input controls with placeholders
