# Changelog — 2026-05-29 04:09:00

## Update
- Hardened card description and comment rendering against HTML/script injection by sanitizing markdown-generated HTML before it is injected into the DOM.
- Removed stale "XSS risk accepted" behavior note in comment rendering and replaced it with explicit sanitization intent.
- Preserved script snippets as visible literal text in newly saved description/comment content by escaping script tags in editor paste/save paths and by escaping disallowed tags server-side instead of discarding them.

## New
- Added shared utility `sanitizeUserGeneratedHtml` in `src/common/utils/sanitizeUserGeneratedHtml.ts`.
- Added shared utility `escapeScriptTags` in `src/common/utils/escapeScriptTags.ts`.
- Wired sanitizer into card description preview rendering in:
  - `src/extensions/Card/components/CardDescription.tsx`
  - `src/extensions/Card/components/CardDescriptionTiptap.tsx`
- Wired sanitizer into comment render pipeline in:
  - `src/extensions/Comment/components/CommentItem.tsx`
- Wired script escaping into description/comment editor save pipelines and script-paste handling:
  - `src/extensions/Card/components/CardDescription.tsx`
  - `src/extensions/Card/components/CardDescriptionTiptap.tsx`
  - `src/extensions/Comment/components/CommentEditor.tsx`
- Updated server rich-text sanitizer mode to retain blocked tags as escaped text:
  - `server/common/sanitize.ts`

## Technical Debt
- Sanitization is currently a client-side defense; server-side validation/sanitization for persisted markdown payloads should also be enforced for defense-in-depth.
- Other markdown-to-HTML paths (e.g. checklist title rendering) should be audited and optionally migrated to the shared sanitizer utility.

## What Should Be Done Next
- Add regression tests covering `<script>`, `javascript:` links, and inline event attributes for card descriptions and comments.
- Enforce equivalent sanitization on API write/read boundaries so unsafe HTML never persists or leaves the backend.
- Run a full pass on remaining `dangerouslySetInnerHTML` call-sites and standardize on the shared sanitizer where content is user-generated.
