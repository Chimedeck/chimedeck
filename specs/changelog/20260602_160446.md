## Update
- Added frontend subscription management flow with a dedicated billing page and checkout redirect page under the new Subscription extension.
- Wired billing and checkout routes into the main app router with support for both singular and plural workspace path variants.
- Added a billing entry in the sidebar user settings menu for the active workspace.
- Moved the billing entry into the main workspace sidebar nav (next to Boards/Members) to avoid confusion with user profile settings links.
- Fixed billing route loading for workspace name/slugs (e.g. `/workspace/journeyhorizon/billing`) by resolving the route token to the workspace ID before API calls.
- Corrected subscription frontend API paths so calls hit `/api/subscription*` and `/api/v1/workspaces/:id/entitlements` correctly.
- Added a visible `Plans` section with per-plan cards and direct checkout CTAs (`Go to Checkout`) for Team/Enterprise.

## New
- New API client module for subscription/billing frontend calls:
  - GET /api/subscription
  - GET /api/v1/workspaces/:workspaceId/entitlements
  - POST /api/subscription/checkout
  - POST /api/subscription/portal
- New pages:
  - /workspace/:workspaceId/billing
  - /workspace/:workspaceId/checkout
  - /workspaces/:workspaceId/settings/billing (alias)
  - /workspaces/:workspaceId/settings/billing/checkout (alias)
- New Subscription translation file for billing and checkout strings.
- New plan presentation strings for Starter/Team/Enterprise card descriptions and checkout CTAs.

## Technical Debt
- Billing page currently surfaces core subscription status and usage meters but does not yet include a full tier comparison grid or 402 upgrade modal interception.
- Route naming is currently mixed (workspace vs workspaces aliases) to preserve compatibility with existing server Stripe return URLs.
