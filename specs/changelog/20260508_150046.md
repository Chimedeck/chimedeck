# Changelog - 2026-05-08 15:00:46

## Update
- Added per-card unread notification bell badge on board card tiles.
- Badge count is computed from unread notifications that have `card_id` and shown on each corresponding card.
- Clicking a card now marks all unread notifications tied to that card as read before navigation to the card modal route.

## New
- Board page now derives `unreadNotificationCountByCardId` and threads it into the Kanban card rendering pipeline.
- Card tile footer now includes a red bell/count indicator for unread card-linked notifications.

## Technical Debt
- Marking unread card notifications currently dispatches one `markRead` request per unread notification id. A batch endpoint could reduce request fan-out for high-volume cards.

## What Should Be Done Next
- Add unit tests for unread count mapping and card click mark-read dispatch behavior.
- Add visual regression or component test coverage for card bell badge rendering states (`0`, `1`, `many`).
