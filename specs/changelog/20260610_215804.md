## Update
- **Fixed `intentWords.size` → `intentWords.length` bug** in `codeSearch`, `gitSearch`, and `docsSearch` connectors — `Array.prototype.filter()` returns an array (`.length`), not a `Set` (`.size`), which was causing all relevance scores to be `NaN` and silently dropping every result.
- **Refactored connectors to dependency injection** — `docsSearch`, `codeSearch`, `gitSearch`, and `cardsSearch` now accept optional DI deps (`glob`, `git`, `db`) so tests can mock filesystem and DB without `vi.mock('bun')`.
- **Fixed `docsSearch` `.size` revert** — `docsSearch` uses `new Set()` so `.size` was correct there; reverted the erroneous change.
- **Fixed gather API import paths** — `api/gather/index.ts` was using wrong depth (`../../../../` instead of `../../..`) for `auth/middlewares/authentication`.

  - `api/index.ts` — router with regex path matching, card ID resolution, board visibility, and feature gating.
