## Update
- Added a new Board Settings section, **Enforceable State Transitions**, that opens a full-screen graph editor overlay for the current board.
- Implemented the graph editor foundation with an accessible dialog shell, keyboard handling (Escape + focus trap), header controls, and a ReactFlow canvas.
- Added feature-flag-aware client wiring so the entry and overlay are hidden/closed when `STATE_TRANSITIONS_ENABLED` is disabled.

## New
- New `src/extensions/StateTransitions/` client feature module with:
  - `api.ts` RTK Query GET/PUT endpoints for board state transitions.
  - Graph editor components (`GraphEditor`, `GraphEditorHeader`, `GraphCanvas`, `ColumnNode`).
  - Graph state and sync hooks (`useGraphEditor`, `useStateTransitionsSync`).
  - `translations/en.json` for all new UI strings.
- Added Redux wiring for `stateTransitionsApi` in reducer registry and store middleware.
- Added `stateTransitionsEnabled` to the `/api/v1/flags` response and client feature flag slice.

## Technical Debt
- Save failure feedback in the graph editor currently uses an inline alert-style banner; this should be aligned to the shared global toast pattern in a follow-up.
- Unsaved-change confirmation uses `window.confirm` and should be replaced with the project’s modal confirmation pattern for consistency.
