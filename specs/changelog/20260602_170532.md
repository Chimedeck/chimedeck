# Changelog

## Update

- Enforced workspace billing visibility to OWNER/ADMIN only by tightening backend authorization on subscription and entitlements endpoints.
- Added server-side subscription access enforcement for board-scoped APIs:
  - `past_due`, `unpaid`, `canceled`, `incomplete_expired` now return 402 payment-required for board access.
  - After 10-day past-due grace, workspace is auto-downgraded to `tier_1`.
  - When downgraded and usage exceeds free limits, workspace board writes are forced into view-only mode.
- Added client-side 402 handling in shared API client to show a payment-required popup and redirect users to workspace billing.

## New

- New subscription enforcement module:
  - `server/extensions/subscription/common/enforcement.ts`
- New request guard middleware:
  - `server/middlewares/subscriptionAccessGuard.ts`
- Added list-route workspace resolution support in request context to ensure enforcement is applied consistently across board/list/card APIs.

## Technical Debt

- The payment-required popup uses `globalThis.alert` as a minimal fallback; replacing it with a product-native modal/toast pattern would improve UX consistency.
- Board access route classification in `subscriptionAccessGuard` is path-pattern based; if new board-adjacent routes are added, they must be included explicitly.

## What Should Be Done Next

- Add integration tests for subscription guard behavior across:
  - blocked board reads (payment required)
  - read-only write denials after free-tier downgrade overages
  - billing endpoint access for OWNER/ADMIN vs MEMBER/VIEWER/GUEST
- Validate frontend UX in Playwright for 402 redirect flows from board pages to billing.
- Consider adding an explicit persisted billing-state marker for downgraded delinquent workspaces to improve observability/audit trails.
