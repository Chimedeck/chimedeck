## Update
- Added `GET /api/v1/boards/:boardId/state-transitions/rules` endpoint mounted in stateTransitions router.
- Extended `server/extensions/list/api/delete.ts` to strip deleted-list nodes and their edges from the board's state transition graph on list deletion.
- Extended `server/extensions/list/api/update.ts` to update node labels in the state transition graph when a list is renamed.
- Added WS broadcast of `state_transition_updated` event (via pubsub publisher) after every successful PUT to state transitions.

## New
- `server/extensions/stateTransitions/api/getRules.ts`: Returns normalised rules JSON with `current_state`, `allowed_next_states`, and `forbidden_next_states` for each node. Nodes with no outgoing edges are treated as fully locked.
- `server/extensions/stateTransitions/common/sync.ts`: `stripDeletedNodes(graph, activeLists)` removes nodes whose listId is no longer in the active lists and prunes orphaned edges; `updateNodeLabels(graph, activeLists)` refreshes node labels to match current list titles.
- `server/extensions/stateTransitions/api/__tests__/getRules.test.ts`: Unit tests — empty-graph returns empty rules array; one-way + two-way edges produce correct `allowed_next_states` / `forbidden_next_states`.
- `server/extensions/stateTransitions/api/__tests__/put_ws.test.ts`: Verifies `state_transition_updated` WS event is published after a valid PUT.
- `server/extensions/stateTransitions/common/__tests__/sync.test.ts`: Unit tests for `stripDeletedNodes` and `updateNodeLabels`.
- `server/extensions/stateTransitions/common/__tests__/validator.test.ts`: Unit tests confirming `node.id` must match `node.listId` and unknown listId detection.
- Fixed `validator.ts` to enforce `node.id === node.listId` invariant.

## Technical Debt
- List sync hooks run synchronously inside the list mutation path; a failed graph update will roll back the list rename/delete. Consider decoupling with an async event in a future iteration.
- `put_ws.test.ts` tests the event payload shape but does not exercise a real WebSocket connection.
