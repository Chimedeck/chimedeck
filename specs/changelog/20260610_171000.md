## Update
- `server/mods/flags/defaults.ts`: Added `INNER_CARD_CHAT_ENABLED: false` (off by default).
- `server/index.ts`: Imported and invoked `cardChatRouter` in the request pipeline after `cardRouter`; exposed `innerCardChatEnabled` in the `GET /api/v1/flags` response.
- `src/slices/featureFlagsSlice.ts`: Added `innerCardChatEnabled: boolean` to `FeatureFlagsState`, `initialState`, API response union, `fulfilled` reducer, and exported `selectInnerCardChatEnabled` selector.

## New
- `db/migrations/20260610_card_chat_schema.ts`: Migration creating `card_chat_sessions` (id, card_id, workspace_id, created_by, status with CHECK constraint for IDLE/ACTIVE_REFINEMENT/PAUSED/READY_FOR_REVIEW, quality_score, last_actor_at) and `card_chat_messages` (id, session_id, role, content, metadata JSONB, author_id, created_at) with foreign keys to cards/users/workspaces and composite indexes for `(session_id, created_at, id)` cursor pagination.
- `server/extensions/cardChat/`: New extension following the `api/` + `mods/` + `common/config/` folder structure.
  - `types.ts`: All interfaces — `CardChatSession`, `CardChatMessage`, `CardChatSessionStatus`, `CardChatMessageRole`, `WriteCardChatMessageInput`, `StartSessionInput`, `PauseSessionInput`.
  - `common/config/index.ts`: Exports `INNER_CARD_CHAT_FLAG_KEY` constant.
  - `mods/session/lifecycle.ts`: `startSession` (creates IDLE→ACTIVE_REFINEMENT), `pauseSession` (validates ACTIVE_REFINEMENT→PAUSED, rejects invalid transitions), `ensureActiveSession` (returns existing active session or creates new — one active session per card). All accept single destructured args.
  - `mods/messages/write.ts`: `writeCardChatMessage` — validates session is in ACTIVE_REFINEMENT (rejects PAUSED with `session-is-paused`, 409), normalizes content, inserts message, bumps `last_actor_at`. Dep injection via `cardChatWriteDeps`.
  - `mods/messages/query.ts`: `getCardChatMessages` — cursor-paginated `(created_at, id)` keyset query with `limit + 1` / `slice(0, limit)` pattern, joins users for author name+avatar.
  - `api/index.ts`: `cardChatRouter` — matches `/api/v1/cards/:cardId/chat[/sub]`, applies `applyBoardVisibilityFromCard`, feature-flag-gates via `flags.isEnabled('INNER_CARD_CHAT_ENABLED')` returning 404 with `inner-card-chat-disabled`, dispatches to message/session sub-handlers.
  - `api/session/start.ts`: `POST /api/v1/cards/:cardId/chat/session/start` — guard chain (authenticate → workspace membership → flag gate), idempotent (returns existing active session).
  - `api/session/pause.ts`: `POST /api/v1/cards/:cardId/chat/session/pause` — validates state transition, returns 409 on already PAUSED.
  - `api/messages/create.ts`: `POST /api/v1/cards/:cardId/chat/messages` — validates `{ sessionId, content }`, rejects writes on PAUSED sessions (409).
  - `api/messages/get.ts`: `GET /api/v1/cards/:cardId/chat/messages` — cursor-paginated with author join, returns `{ data, metadata: { cursor, hasMore } }`.
