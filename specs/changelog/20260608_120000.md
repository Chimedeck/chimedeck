# Update
- Refactored subscription persistence from workspace ownership to user ownership.
- Workspace creation quota now resolves maxWorkspaces from the user's billing tier instead of joining per-workspace subscription rows.
- Billing API endpoints now resolve and mutate the authenticated user's subscription record.
- Billing navigation in UI is now visible to workspace members (billing is account-level).
- Usage aggregation now computes storage and total boards across all workspaces owned by the workspace owner.

# New
- Added migration db/migrations/20260608_user_subscriptions.ts.
  - Creates user_subscriptions with one canonical row per user.
  - Backfills from workspace_subscriptions by selecting the strongest/latest tier per workspace owner.
- Added user-scoped helpers in subscription repo:
  - getByUserId
  - getOrCreateByUserId
  - upsertUserSubscription
  - getCurrentTierForUser

# Technical Debt
- Route paths and UI still use workspace-based billing URLs (/workspace/:workspaceId/billing) even though billing state is now user-scoped.
- Compatibility wrappers remain in subscriptionRepo (workspace-to-user fallback behavior) to avoid breaking older call paths and tests.
- Webhook metadata supports both userId and workspaceId for transition safety; this should be simplified after old checkout sessions expire.
