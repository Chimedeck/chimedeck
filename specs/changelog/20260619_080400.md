# Changelog — 20260619_080400

## Update
- **Board Chat AI: fixed "invalid image input" error for text-only models** — When `search_cards` or `read_attachments` tools return image attachments (base64 data URIs), they are now sanitized based on the active model's vision capability. Text-only models like `deepseek-r1` receive text descriptions (`[Attachment: image/png file]`) instead of raw `image_url` content parts. Vision-capable models (llava, gpt-4o, claude-3, gemma3, etc.) continue to receive full base64 images.

## New
- `isVisionModel(model)` helper — detects vision-capable models via regex patterns
- `sanitizeContentPartsForModel(parts, model)` helper — converts `image_url` parts to text descriptions for text-only models

## Technical Debt
- `executeOneToolCall` (cognitive complexity 39), `runToolUseIteration` (31), and `assistBoardChat` (19) exceed the 15 limit — pre-existing, not introduced by this fix
