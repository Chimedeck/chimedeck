# Card description renders in full in view mode

## Update
None.

## New
`tests/e2e/card-description-expansion.spec.ts`: regression spec seeding a 40-line description via
API and asserting the view-mode preview shows the full content (scrollHeight − clientHeight ≤ 2px)
plus the server-visible round-trip.

## Fixed
Card description in view mode no longer clips long descriptions to a 192px (`12rem`) window.
Root cause: `CardDescriptionTiptap.tsx` (and legacy `CardDescription.tsx`) applied
`maxHeight: 12rem` + `overflow-hidden` with a small "Show more ↓" toggle whenever the description
exceeded 400 chars, hiding ~80% of long descriptions and forcing users into edit mode to read them
(report 2026-10-02: only ~6-8 lines visible). Removed the clamp, gradient overlay, threshold, and
toggle from both components; view mode now renders the whole description (the card modal content
column scrolls for very long content). Verified: 784px clipped → 0px, e2e spec red → green ×2.
