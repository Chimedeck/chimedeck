## Update
- Implemented style-aware edge rendering in state transitions graph editor for `straight`, `orthogonal`, and `smooth` connectors, with legacy `curved` mapped to `smooth` for backward compatibility.
- Added orthogonal segment dragging on edges via an interactive hit-path, including waypoint preview during drag and commit persistence on pointer release.
- Wired waypoint preview/commit callbacks through graph editor hook, canvas, and edge renderer so route edits persist in graph state.
- Extended edge style controls in the inspector to expose `Orthogonal` and `Smooth` options while preserving legacy `Curved` compatibility behavior.
- Added translation keys for the new connector style labels.

## New
- Added a changelog entry documenting the orthogonal routing and segment-drag interaction update.

## Technical Debt
- Orthogonal route auto-layout currently uses a simple midpoint elbow fallback and does not yet perform obstacle-aware routing against node bounds.
- Segment dragging currently targets orthogonal edges only; straight and smooth routes still rely on connector offset control.

## What Should Be Done Next

- Add explicit waypoint handles for insertion/removal and direct point dragging for fine-grained routing.
