## Update
- Hardened link display mode persistence so mode selection is metadata-driven instead of inferred from display label text.
- Fixed mode drift where a mode-1 link with custom display text could be reclassified as mode-2 after rehydration.

## New
- Added explicit link mode metadata class tokens:
  - `cd-link-mode-url`
  - `cd-link-mode-button`
  - `cd-link-mode-card`
- Link mode detection now prefers metadata tokens first; text heuristics are fallback-only.
- Link class builders now write both visual class and mode metadata class together.
