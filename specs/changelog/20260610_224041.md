# Changelog — 2026-06-10

## Update

- **CardModal handler stubs wired to real API calls**: `handleEditRunApprove` now calls `POST /cards/:cardId/ai/edit/:runId/approve`, `handleEditRunRerun` re-triggers sprint generation via `POST /cards/:cardId/sprint/generate`, and `handleFileClick` opens files in a new tab at `/files/:path`. `handleEditRunEdit` navigates to `/cards/:cardId/diff/:runId`.
- **`requiresHumanApproval` added to tier policy**: `TierPolicyResult` now includes `requiresHumanApproval` — `true` for tier_1/tier_2 (lower tiers require human approval), `false` for tier_3+ (auto-approve). The value flows through the sprint generation pipeline into the completed activity event payload, and from there through `SprintGenEvent`/`AsBuiltEvent` to `ApproveRerunControls`.
- **`run-cardchat-tests.sh` extended**: Added 25 stateTransitions test files to the per-file isolation runner. These tests use `mock.module` which causes cross-file contamination when run together — now each file runs in a separate `bun test` process.

## New

- **`SprintArtifactLinks.test.tsx`**: 7 unit tests covering rendering, empty state, icon mapping per artifact type, link `target`/`rel` attributes, custom titles, and label rendering.

## Technical Debt

- CardModal `handleEditRunRerun` currently only re-triggers sprint generation regardless of run type — should distinguish between sprint-gen and as-built-sync runs and call the appropriate endpoint.
- `ApproveRerunControls.test.tsx` uses structural/functional tests rather than React component tests with `@testing-library/react` — these would benefit from proper rendering tests when the test infrastructure supports it.
- As-built sync pipeline always sets `requiresHumanApproval: false` — this could be made tier-aware if approval gating is needed for as-built documentation syncs in the future.

## What Should Be Done Next

- Distinguish run type in `handleEditRunRerun` to call the correct re-trigger endpoint (sprint-gen vs as-built).
- Consider making as-built-sync tier-aware for approval gating.
- Run the full test isolation runner in CI.
