# Changelog - 2026-05-08 15:25:18

## Update
- Generalized notification grouping so all notification types use the same continuous grouping rule when `board_id` + `card_id` tags match.
- `card_created` now groups with other continuous card events under the same board/card tags.
- Grouping remains contiguous-only and does not merge across different card tags (e.g. `test` vs `test2`).

## New
- Notification stack key strategy simplified to a single source: `board-card:<board_id>:<card_id>`.

## Technical Debt
- Notifications without either `board_id` or `card_id` are currently not grouped by this unified strategy.

## What Should Be Done Next
- Add tests for generalized grouping coverage across all notification types in the union.
- Add explicit cases for `card_created` contiguous grouping and `same-board-different-card` non-grouping.
