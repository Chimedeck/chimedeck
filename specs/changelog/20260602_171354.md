# Changelog

## Update

- Added a workspace-creation subscription ownership guard.
- When `SUBSCRIPTIONS_ENABLED=true`, a user cannot create a new workspace if they already own any free workspace (`tier_1` or missing subscription row).
- Workspace creation is allowed only when all owned workspaces are on paid tiers (`tier_2`/`unlimited`).

## New

- New pure policy helper in workspace create API:
  - `findBlockingFreeOwnedWorkspace(rows)`
- New unit tests validating the ownership/subscription creation policy.

## Technical Debt

- The guard currently relies on `workspaces.owner_id`; if ownership semantics evolve to membership-based ownership only, this query should be updated to follow the canonical ownership model.

## What Should Be Done Next

- Add an API/integration test for `POST /api/v1/workspaces` asserting a 402 response payload when a free owned workspace exists.
- Add frontend handling for the new code `workspace-creation-blocked-by-free-owned-workspace` to show a guided upgrade CTA.
