# Changelog — 20260610_205600

## Update

- **Subscription tiers:** Added `'agenticWorkflow'` to `BooleanFeatureKey` union and to `features` map on every tier. Personal (`tier_1`), Hobby (`tier_2`), and Pro (`tier_3`) default to `false`; Business (`tier_4`) and Enterprise default to `true`. This enables tier-aware gating for the trigger engine's premium workflow phases.
- **Feature keys:** Registered canonical key `phase:agentic-workflow` in `server/extensions/subscription/common/featureKeys.ts` for use by the trigger engine's tier gate.

## New

- **Trigger engine (Sprint 173 iteration 7):** Created the async worker, tier gating, and observability infrastructure for the metadata trigger engine:
  - `server/extensions/triggers/common/config/index.ts` — Central config: `PHASE_TIER_MINIMUMS` map (`SYNC_DOCUMENT: tier_2`, `GENERATE_SPRINT: tier_3`, `UPDATE_AS_BUILT: tier_4`), retry policy (3 attempts, 1s/4s/16s backoff).
  - `server/extensions/triggers/common/types.ts` — Shared types: `TriggerRun`, `TriggerAttempt`, `EnqueueTriggerResult`, `TierEligibilityResult`, `TriggerActivityType`.
  - `server/extensions/triggers/mods/tierGate/index.ts` — `evaluatePhaseTierEligibility({ workspaceId, phase })` checks `agenticWorkflow` boolean feature + per-phase minimum tier.
  - `server/extensions/triggers/mods/worker/index.ts` — `enqueuePhaseTriggerRun` validates tier eligibility, persists QUEUED/SKIPPED runs, and fires async dispatch.
  - `server/extensions/triggers/mods/worker/dispatch.ts` — `runTrigger` executes phase workflows with retry and exponential backoff. Stub processors for `SYNC_DOCUMENT`, `GENERATE_SPRINT`, `UPDATE_AS_BUILT` (real workflows deferred to Sprint 175/176).
  - `server/extensions/triggers/mods/persistence/index.ts` — DB helpers: `createTriggerRun`, `createSkippedTriggerRun`, `updateTriggerRunStatus` (with transition validation), `createTriggerAttempt`, `completeTriggerAttempt`.
  - `server/extensions/triggers/mods/idempotency/index.ts` — Deterministic idempotency key generation (`cardId:listId:phase:moveEventId`) and duplicate detection.
  - `server/extensions/triggers/mods/deadLetter/index.ts` — In-memory dead-letter log for exhausted retries.
  - `server/extensions/triggers/mods/activities/index.ts` — Fire-and-forget activity event emission via `dispatchEvent`.
- **Tests:** 38 tests across 4 test files — tier gating (12 tests covering all tier/phase combinations), dispatch (6 tests for state machine and attempt tracking), persistence (13 tests for status transitions and run/attempt CRUD), idempotency (7 tests for key generation and duplicate detection).

## Technical Debt

- Dead-letter log is in-memory only — durable persistence to a DB table deferred to Sprint 174.
- `card_phase_trigger_runs` and `card_phase_trigger_attempts` tables are declared in code but migrations are deferred to iteration 6 (Sprint 173 evaluator). The persistence module handles unique constraint violations gracefully whether the constraint exists or not.
- `TRIGGER_ENGINE_ENABLED_FLAG` constant is defined but the trigger engine is not yet wired into the card-move hook (iteration 6 work).
