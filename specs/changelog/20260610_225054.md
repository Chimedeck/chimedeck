## Technical Debt
- **Flag gating prevents end-to-end testing** — `AI_CONTEXT_ENABLED` defaults to `false`, so both gather and file-scope routes return 404 without manual env-var override; the dev server restart was attempted but the port handoff (Bun on 3000, Vite proxy from 5173) could not be completed in-session
- **Duplicate detection threshold (0.4)** is a magic number calibrated only to test data — real-world tuning may be needed once the feature is live
- **Token estimation** uses a heuristic (charCount / 3) rather than a real tokeniser — adequate for budget decisions but may drift from actual LLM token counts
