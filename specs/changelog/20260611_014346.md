- **barrel export**: Created `src/extensions/SprintGeneration/index.ts` following CardChat export patterns.

## New

- Evidence collector: collects merged PR refs from git log, changed files from git diff, test evidence from changed test files, card metadata from DB
- Doc updater: updates architecture.md, security.md with as-built evidence sections; creates request changelog entries. Preserves YAML front-matter.
- As-built committer: wraps aiEditOrchestrator's commit with as-built message template
- Pipeline orchestrator: 6-step pipeline (create run → collect evidence → update docs → commit → mark succeeded/failed) with activity events
- API handler: auth, card resolution, idempotency check (409 for duplicate), fire-and-forget async pipeline
- 31 tests (19 server + 12 client), all passing

- Client components use placeholder patterns (no real React mounting in tests) — follow same established CardChat/BoardChat test style.
- No DB migration for `card_as_built_sync_runs` — table must be created manually or via a future migration when Knex corruption is fixed.
