## Update

- **CardModal stub handlers replaced with real API calls:** `handleEditRunApprove` now POSTs to `/cards/:cardId/ai/edit/:runId/approve`, `handleEditRunRerun` POSTs to `/cards/:cardId/sprint/generate`, `handleEditRunEdit` opens a diff viewer in a new tab, and `handleFileClick` opens the file path in a new tab. All use the existing `apiClient` pattern from `startCardChatSession`.
- **Card-chat drawer state added to CardModal:** Introduced `chatDrawerOpen`, `chatSession`, and `chatStarting` state with `handleChatStart` (calls `startCardChatSession`), `handleChatClose`, and `innerCardChatEnabled` feature-flag gating. Passed through to the CardModal component as props.
- **Tier-aware approval plumbed into activity renderers:** `SprintGenEvent` and `AsBuiltEvent` now read `requiresHumanApproval` from the event payload and gate the approve button on `isCompleted && requiresHumanApproval` (was previously `isCompleted` alone, rendering approve unconditionally).
- **Test runner expanded to cover stateTransitions:** `run-cardchat-tests.sh` now includes 33 stateTransitions test files (pre-existing cross-file `mock.module` contamination) in the per-file isolation runner, bringing total coverage to 47 files / ~350+ tests.
- **Tier policy resolver added:** `server/extensions/sprintGeneration/mods/tierPolicy/index.ts` determines per-tier sprint caps, feature availability, and `requiresHumanApproval` — lower tiers (1, 2) require human approval; higher tiers (3+) skip it.

## Technical Debt

- Approve/re-run/edit handlers POST to endpoints that may not exist yet (`/cards/:cardId/ai/edit/:runId/approve` from the AI edit orchestrator) — calls will fail silently until those routes are built. Rerun always falls back to `/cards/:cardId/sprint/generate` without distinguishing sprint-gen from as-built runs.
- `quotaEnforcer.ts` still uses module-scoped `quotaEnforcerDeps` — should be refactored to a factory/constructor pattern for proper test isolation.
- Bun `mock.module` cross-file module-cache contamination remains a pre-existing issue affecting the 33 stateTransitions test files when run in bulk (pass when run individually via `run-cardchat-tests.sh`).
- `generateArtifacts` round-robin heuristic may duplicate requirements on the last sprint when `ceil(N/sprintCount)` leaves an empty trailing bucket (pre-existing, documented in earlier changelog).
