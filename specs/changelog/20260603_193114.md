## Update
- Added centralized GitHub App/repository config wiring for the board feature.
- Implemented the GitHub repository download service with installation-token auth, git clone/fetch support, and in-flight/cache deduplication.
- Added unit coverage for repository download and GitHub App token handling.
- Added `simple-git` to support server-side repository operations.

## New
- New board repository-fetch modules under `server/extensions/board/mods/githubRepository/`.
- New typed board GitHub repository config in `server/extensions/board/common/config/githubRepository.ts`.
- New support for repository-scoped GitHub project URLs in the backend download flow.

## Technical Debt
- The board settings UI still rejects repository-scoped GitHub project URLs client-side even though the backend now accepts them.
- The live browser reopen flow was unstable during retest, so the persisted integration state was not fully revalidated end to end.
- Org/user-scoped GitHub project URLs remain unsupported by the download helper because repository resolution is ambiguous.
