# Update
- Moved auth recovery flow into the shared axios client so 401 responses on protected APIs trigger refresh automatically.
- Added queued refresh behavior: concurrent 401 failures now wait for one in-flight `/auth/refresh` call and then retry once.
- On refresh failure (missing/expired/revoked refresh token), client now clears auth state and redirects to `/login?reason=session_expired`.
- Switched bootstrap wiring to use `setClearAuthCallback` from the API client module directly.
- Refresh token TTL is now configurable through `REFRESH_TOKEN_TTL_DAYS` and defaults to 30 days.

# New
- Added `REFRESH_TOKEN_TTL_DAYS` in server env config (default: `30`).
