# Sprint 165 – Board Chat Permission Model + API (Iteration 3)

## Update
- `server/extensions/board/types.ts` — added `BoardChatPermissions` and `PatchBoardChatPermissionsBody` shared types.
- `server/extensions/board/api/index.ts` — mounted `GET /chat-permissions` and `PATCH /chat-permissions` routes in the board router.

## New
- `db/migrations/0119_board_chat_permissions.ts` — creates `board_chat_permissions` table (board-scoped, `guest_can_view`/`guest_can_use` booleans, default false); backfills existing boards.
- `server/extensions/board/mods/chatPermissions.ts` — `normalizeChatPermissions` helper enforcing toggle coupling rules (use=true → view=true; explicit view=false → use=false takes precedence).
- `server/extensions/board/api/chatPermissions/get.ts` — `GET /api/v1/boards/:boardId/chat-permissions`; readable by all board members; returns safe defaults when no row exists.
- `server/extensions/board/api/chatPermissions/patch.ts` — `PATCH /api/v1/boards/:boardId/chat-permissions`; restricted to ADMIN/OWNER; upserts normalized permission row.
- `server/extensions/board/api/chatPermissions/index.ts` — barrel export for the chat-permissions handlers.
- `server/extensions/board/api/__tests__/chatPermissions.test.ts` — 13 tests covering defaults, persistence, ADMIN/OWNER access, MEMBER/GUEST denial, invalid payloads, and toggle normalization.

## Technical Debt
- `board_chat_permissions` backfill in the migration uses `board_id + '-chat-perm'` as a synthetic ID; a UUID would be cleaner but requires a dependency at migration time.

## What Should Be Done Next
