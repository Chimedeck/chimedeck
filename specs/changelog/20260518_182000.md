## New
- `server/extensions/trelloCompat/serializers/customField.ts`: serializers for `TrelloCustomField` (field definition) and `TrelloCustomFieldItem` (card value), with full field-type dispatch (`text`, `number`, `date`, `checkbox`, `list`/dropdown).
- `server/extensions/trelloCompat/api/customFields/index.ts` (~326 lines): full CRUD for `/trello/1/customFields/*`:
  - `POST /customFields` — create field (name, type, idModel/board)
  - `GET /customFields/{id}` — read field definition
  - `PUT /customFields/{id}` — update name, type, pos, display.cardFront
  - `DELETE /customFields/{id}` — delete field and cascade-delete all card values
  - `GET /customFields/{id}/options` — list dropdown options
  - `POST /customFields/{id}/options` — add dropdown option
  - `DELETE /customFields/{id}/options/{optionId}` — remove option (nullifies card value_option_id)
- Card-level custom field endpoints (in `api/cards/index.ts`):
  - `PUT /cards/{id}/customField/{customFieldId}/item` — upsert custom field value per field type
  - `GET /cards/{id}/customFieldItems` — list all custom field values for a card
- `tests/integration/trelloCompat/customFields.test.ts`: 3 tests, 25 assertions covering full CRUD, option management, and card value upsert/read.
