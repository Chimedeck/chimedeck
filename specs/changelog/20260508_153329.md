# Changelog - 2026-05-08 15:33:29

## Update
- Expanded `requireMemberOrBoardGuestMember` to allow board write operations whenever the caller has board-scoped guest access with `guest_type=MEMBER`, even if their workspace role is below `MEMBER`.
- This removes a residual `insufficient-role` failure path for board guest members creating lists.

## New
- Permission helper now checks in this order:
  - workspace role rank (`MEMBER+`)
  - request-scoped `guestType === MEMBER`
  - `board_guest_access.guest_type === MEMBER` in DB (normalized)

## Technical Debt
- Board-guest write behavior is now intentionally board-scoped override logic; endpoint docs should explicitly describe this to avoid role-model confusion.

## What Should Be Done Next
- Add tests for `requireMemberOrBoardGuestMember` where caller role is `VIEWER` but board guest access is `MEMBER`.
- Add end-to-end test for guest member list creation to prevent regressions.
