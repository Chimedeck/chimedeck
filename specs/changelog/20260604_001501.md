# Changelog — 2026-06-04 00:15:01

## Update

- **`SpecsWorkspacePage.tsx` reducer — `save/success` bug fix**: The `save/success` case previously failed to clear `dirtyPaths` after a successful save, so the "Ready to commit" badge never appeared. The fix explicitly removes the path from `dirtyPaths` (and adds it to `pendingCommitPaths`) when `editorContent === savedContent` post-save. The `save/success` return value now always includes the updated `dirtyPaths`.
