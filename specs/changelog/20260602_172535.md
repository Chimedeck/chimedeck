# Changelog

## Update

- Improved create-workspace UX to show the real server-side reason when workspace creation is blocked by subscription policy.
- The modal now displays a specific message when error code is `workspace-creation-blocked-by-free-owned-workspace`:
  - "You can only create more workspaces after upgrading all workspaces you own."
- Added a direct CTA link in the modal to navigate to billing for the blocking free workspace.

## New

- `workspaceShell/create` thunk now preserves structured API error payload (`code`, `message`, and `data`) via `rejectWithValue`.
- Workspace create state now stores typed `createError` details consumed by the modal.

## Technical Debt

- Workspace error mapping is currently in the modal component; extracting a shared error-to-message utility for workspace flows would reduce duplication if more error cases are added.

## What Should Be Done Next

- Add a React component test for `CreateWorkspaceModal` to verify policy-specific messaging and billing link rendering.
- Localize the new policy error text in other language packs if multilingual support is required.
