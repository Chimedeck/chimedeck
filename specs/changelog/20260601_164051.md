# Iteration 4: Tier Config + Limit Helpers (Sprint 159)

## Update
- Added canonical subscription tier quota configuration as single source of truth.
- Added reusable limit calculation helpers for quota math.
- Added feature-key constants for entitlements, gating, and enforcement.

## New

### `server/config/subscription-tiers.ts`
- **`SUBSCRIPTION_TIERS`**: Canonical tier map defining quota matrix for `free`, `pro`, and `enterprise` tiers.
- **`TierQuotas` interface**: Defines 9 quota fields (workspaces, boards, columns, members, guests, storage, rate limits).
- **`QuotaValue` type**: `number | 'unlimited'` for stable type checking.
- **`DEFAULT_UNLIMITED_TIER`**: Fallback tier when subscriptions disabled (enterprise with all unlimited).

Tier definitions:
- **Free**: All numeric caps (1 workspace, 5 boards, 10 columns, 2 members, 1 guest, 100 MB storage, 100 read/30 write RPS).
- **Pro**: Mostly numeric with selective unlimited (5 workspaces, 50 boards per workspace, unlimited total boards/columns, 20 members, 10 guests, 10 GB storage, 500 read/200 write RPS).
- **Enterprise**: All unlimited.

### `server/common/limits.ts`
- **`isUnlimited(quota)`**: Check if quota is unlimited sentinel.
- **`exceeds(usage, quota)`**: Validate usage against quota (returns `false` for unlimited).
- **`remaining(usage, quota)`**: Get remaining capacity (returns `MAX_SAFE_INTEGER` for unlimited).
- **`validate(usage, quota)`**: Type-safe validation returning `{ valid: true }` or `{ valid: false, remaining: number, quota: number }`.
- **`percentageUsed(usage, quota)`**: Compute percentage (0–100, clamped, returns 0 for unlimited).
- **`UNLIMITED_QUOTA`**: Exported sentinel constant.

### `server/extensions/subscription/common/featureKeys.ts`
- **`FEATURE_KEYS`**: Nested object grouping feature keys by domain (workspace, board, list, member, guest, storage, rateLimit).
- **`ALL_FEATURE_KEYS`**: Flat array of 9 unique keys following naming convention `domain:action` (hyphenated).
- **`FeatureKey` type**: Union type for all feature key values.

Feature keys:
- `workspace:max-workspaces`
- `board:max-per-workspace`, `board:max-total`
- `list:max-per-board`
- `member:max-invited-per-board`
- `guest:max-per-board`
- `storage:max-bytes`
- `ratelimit:read-per-minute`, `ratelimit:write-per-minute`

## Technical Debt
- Tier quotas are hardcoded; consider externalizing to environment or database in production.
- Rate limit sentinel is currently `'unlimited'` string; could be refined to const enum for exhaustiveness checking.
