# Changelog - 2026-05-08 15:12:06

## Update
- Refined notification continuous grouping to require matching board+card tags, not just board.
- This prevents grouping across different cards in the same board (e.g. `test` and `test2` no longer merge).
- Notification card header now always shows a clickable card title for card-related items.
- Added compact board and card tags next to header metadata so users can see exactly which card context each group belongs to.

## New
- Introduced board+card stack key strategy in notification panel grouping (`board-card:<board_id>:<card_id>`).
- Added card-context tag row in notification item header (`board tag` + `card tag`) for card-related groups.

## Technical Debt
- Card/activity tag labels in header are currently using existing raw title fields; future enhancement could include truncation rules and tooltip consistency for long names.

## What Should Be Done Next
- Add tests that verify:
  - contiguous same board+card notifications group
  - contiguous same board but different card do not group
  - non-contiguous same board+card do not group
- Consider localizing or tokenizing card-tag styling if design system adds dedicated metadata chip components.
