# Changelog — 20260619_073500

## Update
- **Board Chat multi-turn context retention**: Changed `buildAssistMessages()` in `server/extensions/board/mods/chat/assist/index.ts` to inject previous conversation messages with their proper `user`/`assistant` roles instead of lumping them into a single `system` message. This enables the AI to resolve anaphoric references (e.g. "in there" → "the card we were discussing") across turns.

## Technical Debt
- `buildAssistMessages()` still injects the tool list as a system message — this is fine for now but could be moved to a dedicated `developer` role message for providers that support it.

## What Should Be Done Next
- Consider storing tool call metadata (tool name, arguments, results) alongside messages in `board_chat_messages` so the AI can reference structured data from previous turns, not just the final text summary.
