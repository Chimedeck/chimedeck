# Changelog — 2026-06-10 19:45 UTC

## Update

### Sprint 172 Wiring — Phase Editor UI + Cache Invalidation + Feature Flag

**Column phase inspector wired into graph editor:**
- `GraphCanvas.tsx` now renders `ColumnPhaseEditor` as a floating panel (mirroring `EdgeInspector` pattern) when a single column node is selected and no edge inspector is open.
- Phase changes propagate to `useGraphEditor` via new `setNodeData` callback — marks the graph dirty so the Save button activates.
- Clicking away (pane click or Escape) closes the inspector; selecting a different node switches context.

**Phase cache invalidation wired to WS:**
- `broadcastStateTransitionUpdated` in `common/ws.ts` now calls `invalidatePhaseCacheFromStateTransitionEvent` before publishing, ensuring WS receivers read fresh phase data after graph saves.

**Feature flag `AGENTIC_WORKFLOW_ENABLED` added:**
- Server: `server/config/featureFlags.ts`, `server/mods/flags/defaults.ts` (default `false`), exposed at `GET /api/v1/flags` as `agenticWorkflowEnabled`.
- Client: `src/slices/featureFlagsSlice.ts` — state, selector `selectAgenticWorkflowEnabled`, and fetcher updated.
- `.env.example` documents `FLAG_AGENTIC_WORKFLOW_ENABLED=false`.
