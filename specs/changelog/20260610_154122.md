# Changelog — 2026-06-10 15:41 UTC

## Update

- **aiContext router registered** — `server/index.ts` now imports and mounts the `aiContextRouter`, so `POST /api/v1/cards/:cardId/ai/context/gather` and `POST /api/v1/cards/:cardId/ai/file-scope` are live. Previously the router existed but was dead code.
- **AI_CONTEXT_ENABLED feature flag** — added to server config (`server/config/featureFlags.ts`), client Redux slice (`src/slices/featureFlagsSlice.ts`), and defaults (`server/mods/flags/defaults.ts`). The router gates on this flag (returns 404 when disabled).
- **Gather + fileScope handler cleanup** — removed redundant `currentUser` null check from both handlers (`handleGatherContext`, `handleFileScope`) since `authenticate` already validates the user. Fixes testability with mocked auth.

## New

- **Budget management** (`server/extensions/aiContext/mods/budget/`) — `applyBudget()` enforces token (8 000 default) and size (100 KB default) budgets on context chunks. Drops lowest-confidence chunks first. `estimateTokens()` uses 4-char-per-token heuristic. 8 tests.
- **Duplicate detection** (`server/extensions/aiContext/mods/duplicateDetection/`) — Jaccard similarity on keyword sets (≥ 3 chars), 0.4 threshold. Capped at `MAX_CHUNKS_PER_CONNECTOR` results. Injectable `DuplicateDB` for testing. 6 tests.
- **Impact analysis** (`server/extensions/aiContext/mods/impactAnalysis/`) — Scans `specs/` for `.md` files, computes word overlap with gathered context chunks. Boosts recently-modified files 1.2×. Threshold 0.1. Injectable `ImpactFS`. 5 tests.
- **File scope planner** (`server/extensions/aiContext/mods/fileScopePlanner/`) — `planFileScope()` produces `create`/`edit`/`no-change` plan combining gathered context, duplicates, and impact analysis. Protected files (e.g. architecture) always `no-change`. Creates sorted before edits. 8 tests.
- **Context snapshot persistence** (`server/extensions/aiContext/mods/snapshots/`) — SHA-256 hash via Web Crypto `SubtleCrypto`. `persistSnapshot()` writes to `card_ai_context_snapshots` table. Best-effort: failure logged, doesn't fail the caller. Injectable `SnapshotDB`. 6 tests.
- **File scope API** (`server/extensions/aiContext/api/fileScope/`) — `POST /api/v1/cards/:cardId/ai/file-scope` chains gather → budget → duplicate detection → impact analysis → file scope planning → snapshot persistence. Returns `FileScopeResponse` with `files[]`, `possibleDuplicateCards`, `confidence`. 5 tests.
- **DB migration** (`db/migrations/20260610_card_ai_context_snapshots.ts`) — `card_ai_context_snapshots` table with `id`, `card_id`, `intent`, `snapshot_hash`, `total_chunks`, `chunks_json`, `budget_json`, `focus_paths` (JSONB array), `created_at`. Indexed on `card_id` and `snapshot_hash`.

## Technical Debt

- **Gather test import path fixed** — changed `await import('../index')` to `await import('../gather')` in `gather.test.ts`. The old path resolved to the router which doesn't export `handleGatherContext`. This was a latent bug surfaced by the router refactor.
- **Bun `vi.mock` path resolution from nested test dirs** — `api/__tests__/fileScope/index.test.ts` couldn't use `vi.mock` because Bun resolves module paths differently from deeply nested directories. Workaround: directly patch `fileScopeApiDeps` exports instead.
