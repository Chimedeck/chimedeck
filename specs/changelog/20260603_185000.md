## Features

### GitHub Project URL Setting Component
- **Validation:** Regex validates against `https://github.com/{orgs|users}/[name]/projects/[number]` with optional trailing slash
- **URL Normalization:** Automatically removes trailing slashes on save
- **Optimistic UI:** Flips state immediately, rolls back on API failure with error message
- **Load State:** Shows loading skeleton while fetching initial value
- **Disabled State:** Shows unauthorized message and disables all controls for non-admins
- **Clear Function:** Sends `null` to clear the setting; visible only when URL is present

### Integration with Existing Systems
- **Permissions:** Only workspace OWNER/ADMIN can edit; all members can view current setting
- **API Layer:** Uses existing board API client pattern with typed helpers
- **Styling:** Matches existing BoardSettings component design (dark theme, consistent colors)
- **Accessibility:** ARIA labels, helper text, proper focus management

## Architecture Decisions

- **Borrowed Pattern:** Optimistic save + rollback from `BoardNotificationToggle`; gating pattern from `VisibilitySelector`
- **No Backend Dependency:** Backend integration already complete in iteration 9 (migration, API, RBAC, audit)
- **No Visible Indicator:** Field always visible to members but disabled for non-admins (vs hidden); aligns with transparency goal
