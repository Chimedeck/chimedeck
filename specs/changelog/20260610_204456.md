# Changelog — 2026-06-10 20:44 UTC

## Update

- **Wired sprint generation activity events to DB persistence**: `server/extensions/sprintGeneration/mods/activities/index.ts` now calls `writeActivity()` + `publishCardActivityEvent()` instead of `console.log`. All 6 sprint gen event types (started, artifact_created, card_created, quota_exceeded, completed, failed) persist to the activity table and broadcast via websocket.
- **Wired as-built sync activity events to DB persistence**: `server/extensions/asBuiltSync/mods/activities/index.ts` receives the same treatment for all 6 as-built event types (started, evidence_collected, docs_updated, committed, completed, failed).
- **Registered 12 new activity event types** across three config files: server `visibleEventTypes.ts`, client `activityEventsConfig.ts`, and client `activityEventLabels.ts` — all sprint 176 events are now visible in the card activity feed with human-readable labels.
- **Created `CardActivity` client extension** (`src/extensions/CardActivity/`) with rich event renderers for sprint generation and as-built sync events. `SprintGenEvent` renders diff summaries, artifact links, and approve/re-run controls. `AsBuiltEvent` renders diff summaries and commit links. The `ActivityEventRenderer` dispatcher routes by event type prefix.
- **Integrated rich event rendering into card ActivityFeed**: `Card/containers/CardModal/ActivityFeed.tsx` now conditionally renders `ActivityEventRenderer` for `sprint_generation_*` and `as_built_sync_*` events, falling through to the existing text label for all other events.
