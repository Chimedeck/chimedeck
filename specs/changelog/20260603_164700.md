## Update
Implemented the Board Chat write path end to end: chat messages now persist as raw rows first, then store vector metadata when embedding succeeds, and failed embeddings can be retried without duplicating the message row.

Wired `POST /api/v1/boards/:boardId/chat/messages` into the board router, added board-level chat message types, and updated the Board Chat client to fetch and render persisted history.

Fixed a retry-path serialization bug so vector payloads persist correctly in `jsonb`, and tightened the live archived-board / unauthorized rejection flow.

## New
Added `board_chat_threads`, `board_chat_messages`, and `board_chat_message_vectors` storage with board-scoped indexes and foreign keys.

Added board chat message write, embedding, and retry modules, plus API coverage for create/history behavior and access validation.
