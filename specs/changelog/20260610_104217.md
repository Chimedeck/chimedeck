## Technical Debt

- `featureFlagsSlice.fetchFeatureFlagsThunk.fulfilled` handler uses type assertions (`as Record<string, unknown>` then `as { ... }`) to narrow the API response union type. The underlying issue is that `apiClient.get` returns a 3-way union (`{ data } | payload | AxiosResponse`) where the raw-payload branch and AxiosResponse branch don't have `.data`. This was cleaned up for the CardChat additions but the root cause (ambiguous apiClient type) should be resolved at the apiClient level.
- `QualityScoreMeter.colorForScore` uses non-null assertions (`!`) on `Record<string, string>` index access — acceptable since all keys are explicitly defined, but could be eliminated with a proper enum.
