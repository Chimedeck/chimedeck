## Technical Debt

- Existing typecheck returns the same 456 baseline diagnostics; lint cannot load the existing undeclared `typescript-eslint` package. See `specs/tests/mobile-push-verification.md` for comparison evidence and focused passing checks.
- Enqueue follows publication on a best-effort basis rather than an atomic outbox; ambiguous delivery acknowledgements can cause duplicates. Failed jobs currently need operator retention/inspection policy.
- The legacy Dockerfile copies `.env` into its image. Keep push private keys in runtime-mounted ADC files, outside build context; broader deployment secret handling is outside this feature.
