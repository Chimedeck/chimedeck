# Changelog — 2026-06-10 16:56 UTC

## New

### Sprint 175 — AI Edit Orchestrator Execution Pipeline

Implemented the full 5-step execution pipeline for the AI Edit Orchestrator, plus approve/reject endpoints and resume/retry logic:

- **Path Guard** (`mods/pathGuard/`): Validates file paths are within allowed write zones (`specs/request_changelog/`, `specs/sprints/`, `specs/architecture/`, `specs/security/`). Rejects path traversal, `.git`, `node_modules`, empty paths. Normalises relative references. 14 tests.

- **File Creator** (`mods/fileCreator/`): Creates new markdown files under allowed paths with front-matter. Idempotent — skips if file already exists. Handles parent directory creation. 3 tests.

- **File Editor** (`mods/fileEditor/`): Applies structured search-and-replace edits while preserving YAML front-matter. Validates front-matter before and after edit, rejects corrupting edits. Supports line-range constraints and append-on-missing. 5 tests.

- **Front-Matter Guard** (`mods/fileEditor/frontMatterGuard.ts`): Parses YAML front-matter and validates against known doc type schemas (request_changelog: title/date/status; sprint: sprint_number/title/status/start_date; architecture/security: title/last_updated). 9 tests.

- **Committer** (`mods/committer/`): Stages only run-scoped files, creates git commits with standardised messages (`feat(ai-edit): {intent} [{cardId}] [REVIEW]`), pushes to origin. Handles push failures and "nothing to commit" gracefully. 3 tests.

- **Resume** (`mods/resume/`): Resumes a failed run from the last successful step. Determines remaining steps, checks retry limits (MAX_RETRY_ATTEMPTS=3). Validates only FAILED runs can be resumed. 13 tests.

- **Orchestrator** (`mods/orchestrator/`): Executes the full pipeline sequentially: context_gather → file_scope_plan → files_create → files_edit → commit. Advances run status after each step, creates/updates step records, handles per-step failures with FAILED transition.

- **Approve/Reject endpoints** (`api/approve/`, `api/reject/`):
  - `POST /api/v1/cards/:cardId/ai/edit/:runId/approve` — validates run is COMMITTED and not already approved/rejected
  - `POST /api/v1/cards/:cardId/ai/edit/:runId/reject` — requires reason, transitions run to FAILED

- **Router** (`api/index.ts`): Extended to match approve/reject sub-routes.

- **Edit handler** (`api/edit/index.ts`): Fires orchestrator pipeline asynchronously after run creation with a null-safe guard.

- **Config** (`common/config/index.ts`): Added COMMIT_MESSAGE_TEMPLATE and APPROVED_COMMIT_MESSAGE_TEMPLATE.

- **Types** (`types.ts`): Added ApprovalStatus, pipeline step types, PIPELINE_STEPS, STEP_TO_STATUS, and all related interfaces (CreateFileInput/Result, EditFileInput/Result, etc.).
