## Update
- Added a list-column collapse/expand control in the list header, positioned beside the existing `...` menu trigger.
- Column collapse state is now user-local and not shared via API/server.
- Collapse preferences persist in localStorage and sync live across browser tabs.

## New
- New per-user, per-board localStorage key for collapsed list IDs.
- Cross-tab synchronization using the `storage` event so toggling in one tab updates others immediately.
- Collapsed columns render as compact columns (header-only), while expanded columns keep full card/content rendering.

## Technical Debt
- Column collapse state currently stores only list IDs (boolean collapsed). If additional per-list UI preferences are introduced, a shared board UI preferences schema should replace ad-hoc keys.
